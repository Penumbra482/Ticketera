Falta levantar el servidor

Tres Tickets no es una página suelta: necesita su servidor, que es el que guarda los eventos, las butacas y las entradas. Abrí una terminal en la carpeta del proyecto y ejecutá: 

npm start

Después entrá a http://localhost:4000 desde el navegador. No hace falta npm install: el proyecto no tiene dependencias. Sí hace falta Node 22.5 o más nuevo (node -v para verificarlo).

Si estás viendo este cartel es porque abriste web/index.html directamente desde el explorador de archivos. Así el navegador no puede cargar los módulos de la aplicación (los bloquea por seguridad en file://) ni hablar con la API.
